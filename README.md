# Invite Studio

Интерактивные свадебные приглашения: opening animation, музыка, countdown, программа, площадка, детали и RSVP.

## Текущий релиз
V7 — основной рабочий шаблон.

## Структура
- `index.html` — основное приглашение
- `landing/` — продающий лендинг
- `demo/` — демо-версия
- `opening-test/` — отдельный тест opening engine
- `api/` — backend заявок и RSVP
- `admin/` — простая админка
- `qa/` — self-QA и release gate

Все дальнейшие правки вносятся напрямую в этот репозиторий.
