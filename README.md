# Invite Studio

Интерактивные свадебные приглашения с премиальным визуалом, opening-анимацией, музыкой, countdown, программой дня, площадкой, деталями для гостей и RSVP.

## Текущий релиз

**V10 — GPT Image Luxury Template**

Живая версия: https://landify-pro.github.io/invite-studio/

### Что входит
- закрытый конверт с сургучной печатью;
- поэтапная анимация открытия: реакция печати → свечение → свет по швам → раскрытие → приглашение;
- отдельный hero для desktop и mobile;
- русский контент;
- живой countdown до 21 июня 2027;
- программа свадебного дня;
- блок ресторана «Турандот» и маршрут;
- детали: подарки, трансфер, проживание, dress code;
- RSVP modal;
- QR-блок;
- музыкальная кнопка;
- responsive layout для телефона, ноутбука и desktop.

## Дизайн-политика

Визуальный арт проекта создаётся через **GPT Image**. CSS/HTML используются для композиции, адаптива, анимации и функциональности, но не для самодельных иллюстраций, дворцов, конвертов или другого ключевого арта. Полное правило — в `DESIGN_POLICY.md`.

## Runtime assets

Из-за ограничений текущего GitHub-коннектора GPT Image-графика хранится в `runtime/` как base64-фрагменты AVIF и собирается браузером при загрузке страницы. Пользователю ничего скачивать или загружать вручную не нужно.

## RSVP

Текущая публичная демо-версия сохраняет ответ локально в браузере. Для реального клиентского проекта подключается адресат: Telegram, Google Sheets или другой backend endpoint.
