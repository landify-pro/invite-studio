# Invite Studio

Интерактивные свадебные приглашения с премиальным визуалом, opening-анимацией, музыкой, countdown, программой дня, площадкой, деталями для гостей и RSVP.

## Текущий релиз

**V16 — Real Video Opening + Seamless Card Bridge**

Живая версия: https://landify-pro.github.io/invite-studio/

### Что входит
- закрытый конверт с сургучной печатью;
- настоящее видео открытия конверта на мобильных устройствах;
- бесшовный переход из чистой видеокарточки в HTML-экран с именами и датой;
- поэтапная CSS-анимация остаётся временной desktop-версией до получения горизонтального ролика;
- отдельные чистые GPT Image-фоны без текста и интерфейса для desktop и mobile;
- весь текст и все кнопки собраны в HTML и остаются чёткими и интерактивными;
- русский контент;
- живой countdown до 21 июля 2027;
- программа свадебного дня;
- блок ресторана «Турандот» и маршрут;
- детали: подарки, трансфер, проживание, dress code;
- RSVP modal;
- музыкальная кнопка;
- responsive layout для телефона, ноутбука и desktop.

## Дизайн-политика

Визуальный арт проекта создаётся через **GPT Image**. CSS/HTML используются для композиции, адаптива, анимации и функциональности, но не для самодельных иллюстраций, дворцов, конвертов или другого ключевого арта. Полное правило — в `DESIGN_POLICY.md`.

## Графика

Финальные GPT Image-ассеты хранятся отдельными оптимизированными файлами в `assets/images/`: desktop/mobile hero, интерьер площадки, закрытый и открытый конверт, карточка приглашения. Они не содержат нарисованных элементов интерфейса или текста.

## RSVP

Публичная демонстрационная версия сохраняет ответ локально в браузере. Для клиентской версии endpoint указывается в `meta[name="rsvp-endpoint"]`; форма автоматически переключается на отправку JSON и показывает гостю реальный статус.
